### 🏠 Basero: Rental Discovery Platform
> End-to-end room rental discovery platform, built and deployed solo.

- **PostgreSQL** schema with RPC functions, **Row Level Security**, triggers, `pg_cron` cleanup, and PgBouncer pooling
- **Google OAuth** with role-based route protection and Next.js cache invalidation (`unstable_cache`, `revalidateTag`)
- **App Router** architecture with Server Components by default, SEO-focused rendering, and **Google Maps** marker clustering with custom SVG price bubbles
- Deployed on **Vercel** with **Cloudflare** DDoS protection, an **AWS S3** image pipeline, and CI plus AI-assisted code reviews via GitHub Actions and the Gemini API
